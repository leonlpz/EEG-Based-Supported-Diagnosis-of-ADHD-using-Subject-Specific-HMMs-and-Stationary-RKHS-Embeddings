# HMM_RKHS_Classification_Project
EEG-based ADHD classification is challenging due to inter-subject variability. We model frontal EEG with subject-specific HMM–GMMs and embed their stationary distributions in RKHS to compute distances via MMD. These feed KNN/SVM classifiers on synthetic and real data (121 children), with interpretable state dynamics.

Dataset: https://ieee-dataport.org/open-access/eeg-data-adhd-control-children
