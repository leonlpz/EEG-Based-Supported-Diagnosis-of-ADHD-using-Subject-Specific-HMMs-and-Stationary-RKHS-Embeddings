# HMM_RKHS_Classification_Project
EEG-based ADHD classification is challenging due to inter-subject variability. We model frontal EEG with subject-specific HMM–GMMs and embed their stationary distributions in RKHS to compute distances via MMD. These feed KNN/SVM classifiers. On synthetic and real data (121 children), accuracy reached 96%, with interpretable state dynamics.
